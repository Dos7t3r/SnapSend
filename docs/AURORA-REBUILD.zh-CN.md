# Aurora 产品与界面重构（0.6.0 本地开发版）

## 新流程

- USB 检测独立运行。iPhone 无课程也可拍照，确认后先保存；连接 Mac 后续传。
- Mac 接收时按本地时间解析目标：正在上课的 Section → 手动选择 → 收件箱。
- 课程下是固定 Section；Section 保存 ChatGPT 对话 URL 和可选每周课表；日期 Lesson 仅是照片归档。切换日期不需要新绑定。
- 每周课表同日开始/结束，结束时间必须晚于开始时间。重叠课表优先使用其中的手动目标，否则使用目录顺序首项。未支持跨午夜课程。
- 旧课程生成“默认 Section”，原 Lesson ID、照片 ID、文件路径、收据均保留。旧版本的浏览器绑定仅存在内存，已经退出的旧进程无法恢复那份临时绑定；第一次在新 Section 绑定后 URL 会持久化。
- 未发照片在收件箱可多选分配、同时发送、导出或删除。正在发送、未核对的照片不能移动；已发送结果不会被后台自动重排。
- 扩展仍严格校验标签页、完整 URL 和回执。重新绑定不会自动开启发送；用户明确开启后才投递。异常结果必须核对。
- 原生 AI App 投递仍是实验选项，权限检查、应用选择、窗口绑定和仅附图测试已整合到新设置页；浏览器是默认稳定路径。旧设置模板及旧照片界面组件已移除。

## 界面

深色极光背景、浮动侧栏、四段传输路径。概览区分“可以拍照并保存”和“可以自动发送”，给出第一项处理原因。课程采用卡片目录，Section 下按日期展开；菜单栏可看四条状态与最近三张照片。照片大图支持左右键与空格关闭。

统一颜色、字体、间距、圆角、动效参数放在 Theme。原生 macOS 26 玻璃有版本回退；卡片内使用普通透明色块，避免多层玻璃。发送记录用惰性列表，图片由现有后台降采样与有界缓存加载。照片投递状态用 ID 索引查询，今日计数和启动归档修复避免反复扫描全部收据。

背景的 20 秒周期只有 ±0.04 的小幅变化。初次前台实测发现 15 次/秒更新仍有可见开销，因此改成最多每秒一次，仍低于要求的 30 fps 上限。App 非活跃或窗口无焦点时暂停，系统“减少动态效果”下静止。传输缩略图的移动由实际接收和持久化投递事件触发，等待/未确认不会伪装成发送成功。

## 验证与边界

- `swift test`：23 项核心测试，包括 5 项迁移/收件箱/课表/持久化绑定测试和 2 项 USB EOF 耗电回归。
- 浏览器：39 项测试。
- `scripts/check-workspace.sh`：使用临时目录验证无课程接收 → 收件箱 → Section 分配 → 浏览器领取/提交/回执 → USB 重试去重 → 重启恢复绑定。不会向真实聊天上传照片。
- 1080×720 原生 SwiftUI 状态渲染：就绪、手机断开、扩展断开、无 Section、发送中、失败、空记录、收件箱；另有课程和设置页。
- Mac Release 编译和当前机器实际启动、课程/Section/设置页点击检查；iPhone 无签名 Release 编译。此次未向手机签名安装。
- 新的真实 iPhone 拍照至真实 ChatGPT 网页发送，仍需连接设备后验证；隔离测试不等于真机实发。
- 生成截图和性能原始数据位于忽略的 `build/`，不包含在公开源码。现有公开下载仍为 0.5.1；本分支没有发布 0.6.0 Release。

设计自查：侧栏选中项是最亮的固定实心色块；语义色用于状态与小图标；卡片边界及次要文字已检查；主内容采用统一参数。间距采用所给 28/20/16/12/8/4 参数，按 4pt 基准、主要间隔 8pt 倍数处理，保留提示词明确要求的 28 与 20。

## 当前机器的实际运行观察

初次 15 次/秒背景更新出现约 20–40% 的前台 CPU 读数，未以该设置交付。最终每秒一次且明确随 App 活跃状态暂停；包含课程/设置页面切换、断线重试的 24 秒窗口采样中，累计 CPU 从 2.68 秒到 3.03 秒，约增加 0.35 秒，RSS 约 24–49 MB。采样大部分读数为 0.0%，有短暂交互峰值。这不是电池续航或总 GPU 能耗结论；原始数据位于 `build/aurora-final-active.txt`。

重新签名后的启动检查还发现同步钥匙串读取阻塞主线程。已改成后台读取；界面先打开，成功读取后继续自动连接，失败时提供系统提示说明和重试入口。未删除、迁出或放宽旧配对数据的保护。

本机迁移前后逐项比较：51 张照片记录完全相同，所有已发送回执保留。元数据备份在忽略的 `build/aurora-before-migration/`，不上传。

插件面板采用同一深色语义色；主操作按钮紧跟下一步说明，避免被状态列表挤到下面。通过隔离 WebKit 渲染检查 HTML/CSS，桥接状态是测试示例，未向真实聊天发图。独立测试包为 `build/SnapSend-Chrome-Extension-0.6.0.zip`。

扩展重新打开后会从 Mac 恢复 Section 保存的聊天绑定；仅在用户点击修复焦点时打开或激活该聊天。重启后的投递状态索引与历史记录一起恢复，重复 USB 照片回执保留已发送状态。
