# Mac 交互修复与验证

本轮保留极光玻璃视觉，调整点击、滚动、布局与动效。原图、课程目录、配对、扩展协议和发送回执未改动。当前是开发版，尚未发布正式 Release。

## 点击与操作

- 共用 `ClickableRow` / `PressableStyle`。行和卡片的标签撑满宽度；圆角命中区域覆盖内边距。紧凑文字按钮保留原布局，但至少 28pt 高，图标按钮至少 28×28pt。
- 侧栏、手机胶囊、四个管道节点、目标选择、照片行、Section 行、日期入口和筛选均用按钮。没有在文字上挂独立点击手势，也没有列表拖拽手势。
- Section 菜单、照片的发送按钮与整行主按钮互为兄弟，不嵌套，也不由父行的手势一起触发。
- 渐变描边、飞行缩略图、管道连线、极光背景等装饰不接受点击。按钮禁用时淡至 35%，不执行操作。
- Hover 背景白色 6%、0.15 秒。macOS 15+ 使用系统 link 指针；macOS 14 用配对 push/pop，并在禁用和销毁时归还光标。
- 管道的手机节点会启动连接并显示连接设置，避免看不到操作反馈。其他节点分别打开原图归档、扩展安装说明与聊天绑定说明。
- 未插线、尚未绑定和暂停发送是正常等待状态；发送失败、待核对以及已绑定扩展失联才列入“需要处理”。

## 滚动与布局

概览只有一个整页滚动区，卡片没有内部 ScrollView。发送记录显示最新 6 条，日期胶囊或“查看全部”进入独立完整记录页。今日 Section 默认显示 6 个，可展开更多。完整记录、课程、收件箱分别有一个占满内容区的 ScrollView + LazyVStack，系统滚动条在内容区右边缘，未自定义和隐藏。

侧栏自身可滚动，手机连接胶囊用 safeAreaInset 固定底部。概览下方两列的最小宽度各为 340pt；不足时上下堆叠。标题单行，默认 Section 在验证窗口中完整显示。收件箱限制目标选择器宽度，避免最小窗口的工具栏溢出。

## 动效清单

所有自定义动画时间、弹簧与缩放参数在 `Aurora.Motion` 集中定义。

| 动效 | 文件（Sources/SnapSend 下） | 参数 / 触发 |
|---|---|---|
| 导航胶囊滑动、文字颜色 | WorkspaceView.swift | matchedGeometryEffect；spring response 0.38 / damping 0.78；绑定 page |
| 导航图标弹跳 | Components/InteractionComponents.swift | 1 → 1.08 → 1；每段 easeInOut 0.16s；只在选中时触发 |
| Hover、按下、点击后图标 | Components/InteractionComponents.swift | 白色 6% / 0.15s；行缩至 0.98、按钮 0.96；上述弹簧恢复；接受点击后有限 symbol bounce（不宣称 AI 已收到） |
| 页面切换 | WorkspaceView.swift | 旧页 -6pt 淡出、新页 +10pt 淡入；上述弹簧 |
| 卡片错开入场 | Components/InteractionComponents.swift，各 Screens | 每张 0.04s，延迟上限 0.3s；位移 +10pt 与淡入 |
| 卡片 Hover | Theme/AuroraTheme.swift | 上浮 2pt；描边提亮；阴影半径 10 → 14；easeInOut 0.2s |
| 列表新增、删除、状态 | Components/InteractionComponents.swift、Components/AuroraComponents.swift | 新增 -10pt、0.96 → 1 与淡入；删除淡出；颜色弹簧与 replace；绑定记录 ID / 状态 |
| 数字 | WorkspaceView.swift、Components/AuroraComponents.swift、Screens/OverviewScreen.swift | numericText + 状态弹簧（已发送数、记录总数、侧栏数量）；课表分钟用周期刷新 |
| 管道连接与节点 | Components/AuroraComponents.swift | trim 0 → 1，easeInOut 0.6s；断开回灰色虚线；节点有限 pulse |
| 管道流光 | Components/AuroraComponents.swift | 每秒一次调度、线性 1s 向右循环；窗口非焦点或 App 非活跃时暂停 |
| 开关与分段 | Components/InteractionComponents.swift、Screens/OverviewScreen.swift、Screens/SettingsScreen.swift | 开关滑块和 matchedGeometryEffect 分段；上述弹簧 |
| 减少动态效果 | 所有上述组件 | 去掉位移、缩放、弹跳、脉冲、错开延迟和流光，只保留 0.2s 淡入/淡出；背景静止 |

系统菜单、日期/时间选择器、原生 DisclosureGroup 保留系统交互，不重新模拟原生控件。纯文字按钮没有可以弹跳的 SF Symbol。课表剩余时间由分钟级周期刷新，不增加秒级定时器。菜单 popover 与系统符号自身的动画时间由系统控制。

## 仍需实测的范围

- 此轮真实环境没有绑定就绪的 Chrome 聊天，“查看绑定聊天”的启用点击已在模拟连接中验证，真正的 USB → AI 自动投递及 Chrome 执行焦点恢复仍需接回手机与扩展后测试。禁用状态在正式窗口中可见；此轮未发出 AI 消息。
- hover 指针与动画流畅程度需要用户用触控板/鼠标感受；macOS 14 光标兼容分支没有对应运行系统，仅通过编译与释放逻辑检查。
- 减少动态效果已由隔离渲染注入并编译验证，没有擅自改用户的系统设置。连续状态动效与真实课堂耗电需连接实测。一次空闲 CPU / 内存快照不能代表课堂续航。
- 上轮手机拍照速度、音量键、来电/锁屏恢复与手势仍需在 iPhone 上测试；启动成功不等于完成拍照实测。

隔离交互助手首次从 .app 启动时因相对资源路径失败；已改为 Bundle 资源和临时目录，再启动成功并完成上述模拟连接、多 Section 与课程滚动测试。正式 SnapSend 不受此测试助手问题影响。

开发者复测入口：`scripts/check-workspace.sh` 运行自动检查；`scripts/run-mac-interaction-qa.sh` 编译并打开隔离交互窗口。隔离窗口只使用 logo 图片、临时照片目录和模拟扩展心跳；没有启动正式 USB 或扩展服务器。测试结束关闭该测试进程，不应将其当作实际课堂应用使用。
