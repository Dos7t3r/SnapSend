# SnapSend 界面与流程重构 · 2026-10-07

本轮以蓝紫品牌色统一 Mac、iPhone 和 Chrome 扩展。参考图用于视觉层次与材质参考，品牌图经 imagegen 整理成独立应用资产；原始用户文件未修改。

## 已实现

- Mac：独立课程侧栏、课程/日期搜索、课堂工作台、三步连接引导、配对码输入、历史课堂提示、照片详情转场、批量操作及删除确认。
- iPhone：课堂卡片、拍摄/归档/待同步计数、USB 状态、固定拍照入口、课程筛选、历史分组、新设置页、分步骤使用指南。
- 两端：蓝紫渐变、浅色/深色/系统主题、原生玻璃（系统 26+）、旧系统材质回退、减少透明度与减少动态效果适配。
- Chrome：同品牌图标、深色模式、背景投递文案、明确的下一步按钮。
- 保留 USB 协议、课程归档、提示词排队、浏览器投递及原生相册分页/缩放。
- 历史课堂的总结按钮不再向当前课堂误发；安装引导直接打开 AI 配置页；照片卡片取消按钮嵌套；新增 UI 离线预览模式不启动 USB/浏览器服务或打开真实归档。

## 验证与边界

- Mac 编译及应用打包通过；离线 NSHostingView 渲染了浅色/深色工作台。离屏材质/模糊的合成与实际窗口可能不同。
- 34 项浏览器测试、13 项核心测试通过。
- 模拟器 4 项测试通过：图片初始化与旋转、损坏图片提示、分页/缩放稳定性、手机浅色/深色工作台渲染。结果在 build/ui-redesign-render-v3.xcresult。
- iPhone 原生构建在用户要求停止签名安装前通过；此后仅运行模拟器检查，没有安装真机。
- Mac 窗口自动化连续超时，实际窗口交互尚未完成验证。真实 USB 拍摄、既有照片状态、动态效果手感和实际 ChatGPT 投递需后续真机验证。

## 后续验证操作

1. 退出旧 Mac 版本，打开 build/SnapSend.app，检查常用窗口尺寸、主题与课程切换。
2. 用户允许后再覆盖安装 iPhone；检查历史照片、拍照、断线续传与分页手感。
3. 重新加载 Chrome 扩展并刷新聊天；绑定测试课堂，检查提示词、单张照片、批量队列、暂停及总结顺序。

本轮完成的是可构建的界面与流程重构，不代表所有设备环境和 AI 网页版本已穷尽验证。
